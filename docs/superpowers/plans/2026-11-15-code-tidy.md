# Code Tidy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merapikan kode `source/`, `scripts/`, `tools/` (duplikasi, sisa template, lint, kode mati) tanpa mengubah perilaku controller.

**Architecture:** Refactor murni. Jaring pengamannya adalah replay offline rekaman yang sudah ada lewat `scripts/benchmark_stepping.py` (tanpa Isaac): target servo sebelum dan sesudah tiap task harus sama persis. Ekspresi CasADi tidak boleh berubah, jadi build di `outputs/acados/` tetap terpakai (nama build = hash ekspresi).

**Tech Stack:** Python 3.12, uv, ruff (pre-commit), numpy, casadi, pinocchio, acados.

**Spec:** tidak ada dokumen spec; sumbernya permintaan user (2026-11-15) dan audit di bawah.

## Global Constraints

- Belum dieksekusi: plan ini menunggu review user.
- Tidak menjalankan Isaac Lab / Isaac Sim sama sekali (`run_stepping.py`, `run_env.py`, `isaaclab ...`). Verifikasi hanya: replay offline, ruff, `py_compile`.
- Tidak menjalankan install / build / download (`uv sync`, `build_controller.py`). Semua perintah pakai `uv run --no-sync`.
- Komentar: tidak menambah komentar baru. Di Task 1-10 komentar lama hanya ikut pindah bersama kodenya; merapikan isi komentar lama dikerjakan sekali, di Task 11, dengan aturan yang tertulis di sana.
- Jangan reinvent the wheel: pakai yang sudah ada (`pin.Quaternion`, helper yang sudah ada di repo, `benchmark_stepping.py`, ruff). Tidak menambah dependency, framework test, atau modul baru selain yang disebut di task.
- Commit tanpa trailer `Co-Authored-By` dan tanpa `Claude-Session`. Gaya pesan mengikuti log (`refactor(mpc): ...`, `chore: ...`).
- Tidak mengubah angka apa pun: bobot NMPC, konstanta gait, threshold monitor, parameter servo.
- Pre-commit hanya pada file yang disentuh (`uv run --no-sync pre-commit run --files <file...>`), jangan `--all-files`: hook whitespace akan menyentuh `assets/robonionv2/Payload/*.usda` yang tidak boleh diedit.
- Jika replay tidak lagi sama persis, atau muncul `FileNotFoundError ... build not found` (hash berubah): batalkan perubahan task itu dan lapor, jangan rebuild.
